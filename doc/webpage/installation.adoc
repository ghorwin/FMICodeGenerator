== Requirements

The generator requires Python 3 (3.7 or newer) with the packages `pyqt6` (Qt 6) and `send2trash`. Both dependencies are listed in `requirements.txt`, so a plain

[source,bash]
----
pip install -r requirements.txt
----

(inside your virtual environment, if you use one) is usually the simplest option.

To build the generated FMUs you need a C++ compiler, CMake and a zip tool (`7za`/`7z`).

== Linux

=== Ubuntu 24.04 / 26.04

[source,bash]
----
sudo apt install cmake build-essential qmake6 qt6-base-dev python3 python3-pyqt6 \
    python3-send2trash pyqt6-dev-tools p7zip-full
----

The package `pyqt6-dev-tools` contains the script `pyuic6`, needed only for development of the FMIGenerator itself.

=== Fedora 44

[source,bash]
----
sudo dnf install cmake gcc-c++ make qt6-qtbase qt6-qtbase-gui qt6-qtbase-devel \
    python3 python3-pyqt6 python3-send2trash 7zip
----

The package `python3-pyqt6-base` (installed with `python3-pyqt6`) contains the script `pyuic6`, needed only for development of the FMIGenerator itself.

== macOS

Use homebrew and/or macports to install python, pyqt6 and send2trash (or alternatively pip).

== Windows

Things are bit more complicated for Windows. While the code can be compiled (thanks to the CMake build system) using quite a few build chains available on Windows, the batch scripts currently expect a standard Visual Studio 2022 installation, and 7zip must be installed with `7za` in the `PATH`. Also, `cmake` must be in the `PATH`. You also need to install PyQt6 and send2trash (via pip) as dependencies of the script.

If your setup differs from that, edit the files `build_VC_x64.bat` and `deploy.bat` in directory `data/FMI_template/build` (there are example batch files `build_VC_x64_vc2015/2019/2022.bat` for different VC versions). Do this *before* generating an FMU, since generation copies the template as-is.
